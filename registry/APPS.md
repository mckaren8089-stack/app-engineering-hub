# فهرست اپلیکیشن‌ها

این سند فهرست کانونی پروژه‌هاست؛ هر اپ پروژه ChatGPT و GitHub مستقل دارد. آدرس‌ها بدون پارامتر ردیابی‌اند.

| مجموعه | اپ | اجرای مستقیم | مخزن | وضعیت |
|---|---|---|---|---|
| کارن | روزنمای کارن | https://mckaren8089-stack.github.io/karen-rooznama/ | https://github.com/mckaren8089-stack/karen-rooznama | فعال؛ PWA نصب‌شده روی Android 14/15/16، رخداد تاریخی نصب تحت پایش |
| کارن | Karen Fuse | https://mckaren8089-stack.github.io/karen-fuse/ | https://github.com/mckaren8089-stack/karen-fuse | فعال؛ اصلاح کش مشترک ادغام‌شده |

## شروع پروژه تازه
1. ابتدا README و GOVERNANCE مرکز مادر و استانداردهای مرتبط را مطالعه کن.
2. سپس README، Issueها و فایل تحویل مخزن اختصاصی اپ را بخوان.
3. دامنه/Origin، شناسه PWA، Service Worker cache namespace و سیاست بکاپ را قبل از انتشار مشخص کن.
4. لینک اجرای اپ را در سطرهای ابتدایی README فارسی و انگلیسی قرار بده؛ لینک‌ها را بدون پارامتر ChatGPT/UTM نگه دار.
5. فقط قواعد قابل تعمیم را پس از ممیزی به مرکز مادر برگردان؛ داده شخصی، اطلاعات حساس و محتوای داخلی اپ را عمومی نکن.
