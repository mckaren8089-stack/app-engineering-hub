## سندهای این پوشه
- `GOVERNANCE.md`: نحوه همکاری پروژه مادر، پروژه‌های مستقل و چت‌های تخصصی.
- `RESEARCH-PWA-2026-10-30.md`: یافته‌های مشترک نصب PWA؛ فرضیه‌ها و واقعیت‌ها جداست.
- `BACKLOG.md`: وظایف تأییدشده و موارد آینده، از جمله README دو زبانه و سند معرفی محصول.
- `workflow/`: فایل‌های انتقال کار بین چت‌ها و Workها. اینجا محل Snapshotهای اصلی نیست.

## قاعده حقیقت واحد
GitHub در صورت ساخته‌شدن مخزن مادر منبع نسخه‌بندی استانداردها است. این پوشه در Google Drive و کتابخانه ChatGPT، محل مراجعه و بایگانی آن است. سندهای محرمانه و داده‌های شخصی کاربران نباید به مخزن عمومی منتقل شوند.
